<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CAP caller -> cancel API | Caller-provided executionId can alter local execution state or attempt an external stop. |
| CAP plugin -> n8n stop API | Optional n8n stop calls leave CAP and depend on external support and credentials. |
| mock memory -> public query/cancel DTOs | Internal mock records may contain inputs, but public mock results must not expose raw payloads. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-12 | Elevation of Privilege | `cancel(executionId)` | mitigate | Keep cancel as backend CAP service behavior; if exposed over OData later, require CAP authorization before exposure. |
| T-03-13 | Repudiation | unsupported real cancellation | mitigate | Return and persist explicit unsupported/no-op reason when webhook executions cannot be stopped; never mark cancelled without local or n8n confirmation. |
| T-03-14 | Tampering | cancelled queued dispatch | mitigate | Dispatcher checks local source-of-truth status before sending and skips cancelled records. |
| T-03-15 | Information Disclosure | mock query/cancel DTOs | mitigate | Public mock DTOs use the same sanitizing result helpers and omit raw inputs/payloads. |
</threat_model>
