## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry -> local dev dependencies | Dev tooling is installed from npm based on package manifests and lockfiles. |
| smoke tests -> package boundaries | Test code loads workspace packages through public package names and metadata. |
| package pack -> publishable contents | Dry-run packaging exposes what would leave the repository if published. |
