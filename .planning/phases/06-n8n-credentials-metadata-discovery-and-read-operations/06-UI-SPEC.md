# Phase 06 - UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase is an n8n community-node editor surface, not a custom app page. The executor must use n8n credential fields, node property controls, load-options dropdowns, native validation, native credential testing, and n8n item/error semantics. Do not create a standalone frontend, landing page, dashboard, custom CSS design system, or bespoke visual shell.

## n8n Credential Surface

Credential type: `SAP CAP API` (`sapCapApi`)

Field order and exact contract:

| Order | Display Name | Control Type | Required | Default / Placeholder | Display Condition | Description |
|-------|--------------|--------------|----------|-----------------------|-------------------|-------------|
| 1 | Base URL | string | yes | placeholder `http://host.docker.internal:3000` | always | Root URL of the CAP application, without a trailing slash. |
| 2 | Metadata Path | string | yes | default `/odata/v4/admin/$metadata`, placeholder `/odata/v4/admin/$metadata` | always | CAP OData `$metadata` endpoint used for Test Connection and entity discovery. |
| 3 | Authentication | options | yes | default `Basic Auth` | always | Authentication method for CAP OData requests. |
| 4 | Username | string | yes | empty | Authentication = `Basic Auth` | CAP username for Basic Auth. |
| 5 | Password | password | yes | empty | Authentication = `Basic Auth` | CAP password for Basic Auth. |
| 6 | Token URL | string | yes | placeholder `https://your-tenant.authentication.eu10.hana.ondemand.com/oauth/token` | Authentication = `OAuth2 Client Credentials` | OAuth2 token endpoint for the client credentials grant. |
| 7 | Client ID | string | yes | empty | Authentication = `OAuth2 Client Credentials` | OAuth2 client ID. |
| 8 | Client Secret | password | yes | empty | Authentication = `OAuth2 Client Credentials` | OAuth2 client secret. |
| 9 | Scope | string | no | placeholder `openid` | Authentication = `OAuth2 Client Credentials` | Optional space-separated OAuth2 scopes. |

Authentication options:

| Name | Value | Phase 6 Behavior |
|------|-------|------------------|
| Basic Auth | `basicAuth` | Fully working credential path for Test Connection, metadata discovery, Query, and Read. |
| OAuth2 Client Credentials | `oauth2` | Visible scaffold with fields. It must not block Basic Auth acceptance. If runtime support is incomplete, return a sanitized n8n configuration/authentication error instead of leaking token details. |

Do not expose `None` as a visible Phase 6 authentication option. Unauthenticated local-demo support can be revisited only through a later explicit requirement.

Credential test behavior:

| State | Exact User-Facing Copy | Notes |
|-------|------------------------|-------|
| Success | Connection successful. CAP metadata endpoint is reachable. | GET `{Base URL}{Metadata Path}` returned valid metadata response. |
| Network failure | Could not reach CAP metadata endpoint. Check Base URL and network access from n8n. | Do not include raw URL credentials, headers, tokens, stack traces, or full response bodies. |
| 401 | Authentication failed for CAP metadata. Check the SAP CAP API credential. | Category `authentication`. |
| 403 | CAP metadata access is forbidden for this credential. | Category `authorization`. |
| 404 | CAP metadata endpoint was not found. Check Base URL and Metadata Path. | Category `notFound`. |
| 400 | CAP metadata request was rejected. Check Metadata Path. | Category `validation`. |
| 5xx | CAP service returned an error while loading metadata. Try again or check the CAP service logs. | Category `server`. |

## n8n Node Property Surface

Node type: `SAP CAP` (`sapCap`)

Visible Phase 6 operations only:

| Name | Value | Description | Action |
|------|-------|-------------|--------|
| Query | `query` | Retrieve a filtered, sorted, or paged collection of CAP entities. | Query CAP entities |
| Read | `read` | Retrieve one CAP entity by key predicate. | Read a CAP entity |

Create, Update, Delete, CAP actions/functions, and polling trigger options must be removed or hidden from the visible Phase 6 operation selector. They must not be left as selectable inert options because that overstates delivered behavior.

Common field order:

| Order | Display Name | Control Type | Required | Default / Placeholder | Display Condition | Description |
|-------|--------------|--------------|----------|-----------------------|-------------------|-------------|
| 1 | Operation | options | yes | default `Query` | always | CAP OData operation to run. |
| 2 | Service Path | string | yes | default `/odata/v4/admin`, placeholder `/odata/v4/admin` | always | Path to the CAP OData service. |
| 3 | Entity Set Source | options | yes | default `From Metadata` | always | Choose whether to load entity sets from CAP metadata or enter a name manually. |
| 4 | Entity Set | options with `loadOptionsMethod: getEntitySets` | yes | placeholder `Select an entity set` | Entity Set Source = `From Metadata` | Loaded from `$metadata` using the selected SAP CAP API credential. |
| 5 | Entity Set Name | string | yes | placeholder `Books` | Entity Set Source = `Manual` | Use this when metadata cannot be loaded. Enter only the CAP entity set name, not a path or query string. |

Entity Set Source options:

| Name | Value | Behavior |
|------|-------|----------|
| From Metadata | `metadata` | Uses n8n load options to fetch EntitySet names from `$metadata`. |
| Manual | `manual` | Shows `Entity Set Name` string input and bypasses dropdown loading. |

Dynamic dropdown behavior:

| State | Contract |
|-------|----------|
| Loading | Use n8n native load-options loading state. Do not create a custom spinner. |
| Loaded | Show option `name` and `value` as the EntitySet name, for example `Books`; optional description may be the CSDL `EntityType`. |
| Refresh | Use n8n native load-options refresh behavior. Reload when credential, Base URL, Metadata Path, or Entity Set Source changes. |
| Empty | Show `No entity sets found. Check the Metadata Path or switch Entity Set Source to Manual and enter an entity set name.` |
| Failure | Show `Could not load CAP entity sets. Check the SAP CAP credential and Metadata Path, or switch Entity Set Source to Manual.` |

Query-only field order:

| Order | Display Name | Control Type | Required | Default / Placeholder | Description |
|-------|--------------|--------------|----------|-----------------------|-------------|
| 6 | Filter | string | no | placeholder `title eq 'Dune'` | Raw OData `$filter` expression. |
| 7 | Order By | string | no | placeholder `title asc, stock desc` | Raw OData `$orderby` expression. |
| 8 | Select Fields | string | no | placeholder `ID,title,stock` | Comma-separated field list for OData `$select`. |
| 9 | Top | number | no | default `100` | Maximum number of records to return using `$top`. |
| 10 | Skip | number | no | default `0` | Number of records to skip using `$skip`. |

Read-only field order:

| Order | Display Name | Control Type | Required | Default / Placeholder | Description |
|-------|--------------|--------------|----------|-----------------------|-------------|
| 6 | Key Predicate | string | yes | placeholder `ID=201,IsActiveEntity=true` | OData key predicate. Parentheses are optional; examples: `ID=201` or `ID=201,IsActiveEntity=true`. |

## Validation and Interaction Rules

| Input | Rule | Error Copy |
|-------|------|------------|
| Base URL | Must be a valid `http` or `https` URL. Trim one trailing slash for request construction. | Base URL must be a valid http or https URL. |
| Metadata Path | Must be nonempty and start with `/`. Default remains `/odata/v4/admin/$metadata`. | Metadata Path must start with `/`. |
| Service Path | Must be nonempty and start with `/`. Must not contain `?` or `#`. | Service Path must start with `/` and must not include query strings. |
| Entity Set | Required in metadata mode. Values come from `$metadata`; treat names as entity-set names, not URL paths. | Select a CAP entity set. |
| Entity Set Name | Required in manual mode. Reject empty values and obvious path/query delimiters `/`, `?`, `#`. | Enter a CAP entity set name, for example `Books`. |
| Filter | Raw text. Do not parse or validate OData expression grammar in Phase 6. | CAP rejected the OData filter. Check the Filter value. |
| Order By | Raw text. Do not parse or validate OData expression grammar in Phase 6. | CAP rejected the OData order. Check the Order By value. |
| Select Fields | Raw comma-separated text. Do not infer field metadata in Phase 6. | CAP rejected the selected fields. Check the Select Fields value. |
| Top | Nonnegative integer. Preserve `0`; do not drop it through falsey checks. | Top must be a nonnegative integer. |
| Skip | Nonnegative integer. Preserve `0`; do not drop it through falsey checks. | Skip must be a nonnegative integer. |
| Key Predicate | Required for Read. Trim whitespace, wrap with parentheses if missing, preserve inner OData syntax. | Key Predicate is required for Read. |

Interaction constraints:

- Query and Read are GET-only in this phase.
- Do not build a guided query builder, key-field generator, action/function picker, raw response toggle, or mutation body editor.
- Do not parse, rewrite, or URL-encode the full key predicate; preserve CAP/OData syntax such as `ID=201,IsActiveEntity=true`.
- Do not display raw authentication headers, passwords, bearer tokens, client secrets, full CAP response bodies, or stack traces in UI errors, returned error items, tests, fixtures, or docs.

## Output Contract

| Operation | Successful Output |
|-----------|-------------------|
| Query | Return one n8n item per entry in the OData `value` array. Each item `json` is the plain CAP entity object. |
| Query empty result | Return zero n8n items. Do not return the OData wrapper as one item. |
| Read | Return one n8n item containing the fetched entity object. |
| Read not found | Throw a sanitized `NodeOperationError` when `continueOnFail()` is false; return structured error item when `continueOnFail()` is true. |

Cleanup rules:

- Strip every `@odata.*` field by default, including nested `@odata.*` fields.
- Preserve normal CAP entity fields exactly as returned, including casing, associations, nested objects, arrays, booleans, numbers, and nulls.
- Do not add a raw OData response toggle in Phase 6.
- Include n8n `pairedItem` metadata for successful and failed per-item outputs.

## Error Contract

All operational failures must become sanitized n8n-native errors. Use `NodeOperationError` for thrown operation errors and structured item JSON when `continueOnFail()` is enabled.

Structured continue-on-fail item shape:

```json
{
  "error": "CAP rejected the OData request. Check the OData options.",
  "statusCode": 400,
  "category": "validation"
}
```

Exact categories and copy:

| Condition | Status Code | Category | User-Facing Copy |
|-----------|-------------|----------|------------------|
| Bad credentials | 401 | `authentication` | CAP authentication failed. Check the SAP CAP API credential. |
| Forbidden | 403 | `authorization` | CAP authorization failed. This credential cannot access the CAP service. |
| Read entity not found | 404 | `notFound` | CAP entity was not found for the selected entity set and key predicate. |
| Metadata endpoint not found | 404 | `notFound` | CAP metadata endpoint was not found. Check Base URL and Metadata Path. |
| Query/read validation failure | 400 | `validation` | CAP rejected the OData request. Check the OData options. |
| Unexpected OData response shape | n/a | `responseShape` | CAP response did not match the expected OData shape. |
| CAP service failure | 500-599 | `server` | CAP service returned a server error. Try again or check the CAP service logs. |
| Network/connectivity failure | n/a | `network` | Could not reach CAP service. Check Base URL and network access from n8n. |
| OAuth2 scaffold selected but unsupported/incomplete | n/a | `configuration` | OAuth2 Client Credentials is not fully configured for this CAP service. Check the OAuth2 credential fields or use Basic Auth. |

Sanitization rule: error messages, descriptions, returned JSON, and logs must never include `Authorization`, Basic tokens, bearer tokens, username/password pairs, client secrets, raw credential values, full response bodies, stack traces, `.env` values, or private URLs containing embedded credentials.
