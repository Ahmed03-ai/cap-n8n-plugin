<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| n8n credential editor -> CAP $metadata | User-entered Base URL, metadata path, and credentials leave n8n credential storage and reach a CAP OData service. |
| CAP $metadata XML -> n8n load-options dropdown | External XML is converted into design-time entity-set options. |
| n8n node parameters -> request helper | User-entered service path and entity-set mode affect outbound URLs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Information Disclosure | `SapCapApi.credentials.ts`, `GenericFunctions.ts` | mitigate | Inject Basic Auth without serializing usernames, passwords, client secrets, bearer tokens, auth headers, or full CAP response bodies in errors or tests per D-06 and D-23. |
| T-06-02 | Tampering/Elevation of Privilege | `normalizeBaseUrl`, `normalizeMetadataPath`, `normalizeServicePath` | mitigate | Validate URL scheme as `http` or `https`, require leading slash paths, and reject service paths containing query or fragment delimiters before making requests. |
| T-06-03 | Denial of Service/Information Disclosure | `extractEntitySetOptions` | mitigate | Use targeted XML text extraction only for EntitySet names and EntityType descriptions; do not resolve external entities or add an XML parser package in this plan. |
| T-06-04 | Tampering | `SapCap.node.ts` operation metadata | mitigate | Remove visible Create, Update, Delete, CAP action/function, raw response toggle, and polling trigger controls so Phase 6 cannot imply write or trigger support. |
| T-06-SC | Tampering | npm package installs | mitigate | No package-manager installs are planned. If implementation appears to require an XML parser or n8n package upgrade, stop and request a package legitimacy checkpoint instead of installing. |
</threat_model>
