<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| n8n workflow input item -> CAP OData request | User node parameters become authenticated outbound CAP GET requests. |
| CAP OData response -> downstream n8n items | CAP JSON becomes workflow data consumed by later nodes. |
| CAP/OData failure -> n8n execution result | External failures become thrown node errors or continue-on-fail item JSON. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-09 | Tampering | Query URL builder | mitigate | Encode raw OData controls as named query parameters and preserve zero values; do not concatenate arbitrary query strings or add write operations in Phase 6. |
| T-06-10 | Tampering | Read key predicate | mitigate | Require a nonempty key predicate, preserve OData key syntax, and only normalize parentheses so generated key-field UI is not implied. |
| T-06-11 | Information Disclosure | `SapCap.execute` error path | mitigate | Route all thrown and continue-on-fail failures through the Plan 06-02 sanitizer; never throw raw HTTP helper errors or full CAP response bodies. |
| T-06-12 | Spoofing/Information Disclosure | Basic Auth runtime request | mitigate | Send Basic Auth only as transport credential data and assert fake secret values are absent from serialized test outputs. |
| T-06-13 | Tampering | Visible operation metadata and runtime switch | mitigate | Reject or omit operations outside Query and Read so mutation/action/trigger behavior cannot be accidentally executed in Phase 6. |
| T-06-SC | Tampering | npm package installs | mitigate | No package-manager installs are planned. If the executor believes an n8n or XML dependency upgrade is required, stop and request a package legitimacy checkpoint instead of installing. |
</threat_model>
