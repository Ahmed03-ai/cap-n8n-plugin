Create helper contracts for Plan 06-03:
- `stripODataMetadata(value)` recursively removes keys beginning with `@odata.` from objects and arrays.
- `normalizeODataItems(operation, response, itemIndex)` returns `INodeExecutionData[]` for `query` and `read`.
- `classifySapCapError(err, context)` returns a sanitized object with `message`, optional `description`, optional `statusCode`, and `category`.
- `toContinueOnFailItem(safeError, itemIndex)` returns one `INodeExecutionData` item with `json.error`, `json.statusCode`, `json.category`, and `pairedItem`.
- `toNodeOperationError(node, safeError, itemIndex)` or an equivalent helper creates a `NodeOperationError` without embedding raw response bodies or auth data.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CAP OData JSON -> n8n item output | External CAP data is transformed into workflow item JSON. |
| CAP/OData HTTP errors -> n8n errors | External HTTP failures and response bodies are converted into node-visible errors. |
| n8n continueOnFail path -> downstream nodes | Error information becomes workflow item data consumed by later nodes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-05 | Information Disclosure | `classifySapCapError`, `toContinueOnFailItem` | mitigate | Allowlist returned error fields and remove auth headers, tokens, passwords, client secrets, stack traces, request bodies, and full response bodies before throwing or returning items. |
| T-06-06 | Tampering | `normalizeODataItems` | mitigate | Validate expected Query and Read response shapes so unexpected wrapper objects are not passed downstream as trusted entity data. |
| T-06-07 | Repudiation | `toContinueOnFailItem` | mitigate | Preserve `category`, optional `statusCode`, and `pairedItem` so failed item provenance is clear without leaking sensitive details. |
| T-06-08 | Information Disclosure | `stripODataMetadata` | mitigate | Strip OData control metadata by prefix only and preserve normal CAP business fields exactly; do not add raw response output in this plan. |
| T-06-SC | Tampering | npm package installs | mitigate | No package-manager installs are planned. If implementation appears to require a sanitizer or parser dependency, stop and request a package legitimacy checkpoint instead of installing. |
</threat_model>
