<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local workflow export -> sanitizer | Potentially sensitive n8n export data becomes committed app artifacts. |
| sidecar schema JSON -> CDS generator | User-controlled schema data becomes generated CAP CDS. |
| workflow key/path -> filesystem writer | CLI or importer values determine paths under app-root n8n/. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01-ID | Information Disclosure | cap-n8n-plugin/lib/workflows/sanitize.js | mitigate-blocking | Remove credentials, auth headers, owners, emails, shared/project metadata, pinned/static data, and runtime-only fields recursively; Task 1 and Task 3 source gates fail on forbidden fragments. |
| T-05-01-T | Tampering | cap-n8n-plugin/lib/workflows/artifacts.js | mitigate-blocking | Slug workflow keys, reject traversal, resolve absolute paths, and enforce writes under appRoot/n8n before creating files. |
| T-05-01-I | Information Disclosure | demo-app/n8n/**/*.json | mitigate-blocking | Commit only sanitized workflow JSON, scalar schema, and provenance manifest; no raw export or environment data is written. |
| T-05-01-D | Denial of Service | cap-n8n-plugin/lib/workflows/schema.js | mitigate | Reject nested/full schema constructs and cap schema traversal depth to the Phase 5 scalar input object. |
