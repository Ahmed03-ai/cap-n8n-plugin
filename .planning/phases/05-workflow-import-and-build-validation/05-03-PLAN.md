<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generated n8n artifacts -> validator | App-local JSON artifacts influence build diagnostics. |
| CAP CSN annotations -> validator | Developer annotations are inspected and classified. |
| validator -> cds build | Validation messages can fail or pass build output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-T | Tampering | cap-n8n-plugin/lib/workflows/BuildValidationPlugin.js | mitigate-blocking | Throw BuildError when error diagnostics exist so missing required inputs and type mismatches cannot be bypassed by pushed messages alone. |
| T-05-03-I | Information Disclosure | cap-n8n-plugin/lib/workflows/diagnostics.js | mitigate-blocking | Sanitize diagnostic details and exclude raw workflow JSON, API keys, headers, request bodies, stack traces, and .env values. |
| T-05-03-R | Repudiation | cap-n8n-plugin/lib/workflows/validate.js | mitigate | Include entity, annotation, workflow key/reference, input name, mapped field, expected type, actual type, code, and severity in each diagnostic. |
| T-05-03-D | Denial of Service | cap-n8n-plugin/lib/workflows/validate.js | mitigate | Iterate bounded generated artifact manifests and CSN definitions once; deterministic ordering avoids repeated unbounded scans. |
| T-05-SC | Tampering | npm installs | mitigate | No new package installs are planned; use existing CAP build APIs and Vitest. |
</threat_model>
