<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args -> filesystem | Untrusted app, from, workflow, key, schema, and routing values control local reads/writes. |
| live n8n API -> importer | Remote workflow JSON enters the artifact generator. |
| CAP config/env -> HTTP client | API keys and base URLs configure live import requests. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-S | Spoofing | cap-n8n-plugin/lib/workflows/live-client.js | mitigate | Resolve n8n API routing from CAP config/env by default and test expected fake-server endpoints and API-key header behavior. |
| T-05-02-T | Tampering | cap-n8n-plugin/lib/workflows/selection.js | mitigate-blocking | Reject ambiguous multi-workflow imports unless --workflow or --all is explicit, and route selected workflow keys through Plan 05-01 path containment. |
| T-05-02-I | Information Disclosure | cap-n8n-plugin/bin/cap-n8n.js | mitigate-blocking | Do not support or document literal API-key CLI flags; redact env/config secret values from live import diagnostics and tests. |
| T-05-02-D | Denial of Service | cap-n8n-plugin/lib/workflows/live-client.js | mitigate | Use AbortController timeout and bounded JSON parsing; tests use fake HTTP server responses. |
| T-05-SC | Tampering | npm installs | mitigate | No new package installs are planned; use Node built-ins, existing CAP config helpers, and existing Vitest. |
</threat_model>
