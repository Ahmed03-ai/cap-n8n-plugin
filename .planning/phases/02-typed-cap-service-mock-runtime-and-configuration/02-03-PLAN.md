<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CAP runtime -> external n8n webhook | CAP sends outbound HTTP requests to a configured base URL. |
| n8n response/error body -> CAP caller | External response text is transformed into CAP-visible results or errors. |
| retry loop -> n8n workflow execution | Retries may create duplicate side effects if n8n received a previous attempt. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Information Disclosure | transport errors/logs | mitigate | Sanitize errors and logs; never include API keys, auth headers, stack traces, or full inputs. |
| T-02-08 | Denial of Service | webhook requests | mitigate | Enforce a configurable 10 second default timeout with `AbortController`. |
| T-02-09 | Tampering | retry behavior | mitigate | Retry only transient network/502/503/504 failures; never retry 400/401/403/404. |
| T-02-10 | Repudiation | duplicate workflow starts | transfer | Preserve/log correlation metadata and document ambiguity; durable duplicate detection is Phase 3. |
</threat_model>
