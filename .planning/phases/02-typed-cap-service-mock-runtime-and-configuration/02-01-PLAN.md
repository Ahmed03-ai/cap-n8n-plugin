## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CAP app -> `cap-n8n-plugin` | Consumer apps call the package-owned service through `cds.connect.to('n8n')` or package imports. |
| CAP request data -> n8n webhook payload | Caller-provided inputs leave CAP and become JSON request bodies to n8n. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `workflowId` path normalization | mitigate | Validate workflow ID type and normalize only one leading slash; preserve only documented `webhook/` and `webhook-test/` prefixes. |
| T-02-02 | Information Disclosure | start result envelope | mitigate | Return only normalized response data and caller-provided safe metadata; no headers, secrets, stack traces, or transport internals. |
| T-02-03 | Repudiation | correlation metadata | mitigate | Preserve optional `correlationId` and `businessKey` in the result envelope without claiming durable tracking before Phase 3. |
</threat_model>
