<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CDS model -> annotation parser | Developer-authored annotations become executable runtime configuration. |
| Condition string -> evaluator | Developer-authored `if` text controls workflow side effects. |
| Entity data -> workflow payload | CAP row data is transformed into n8n dispatch payloads. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01-01 | Elevation of Privilege | `ConditionEvaluator.js` | mitigate | Parse with `cds.parse.expr`, whitelist scalar CXN nodes/operators, and block `eval` and `new Function` with source-gate verification. |
| T-04-01-02 | Tampering | `AnnotationParser.js` | mitigate | Validate event values, annotation shape, scalar mappings, and businessKey at registration time; throw `ERR_N8N_ANNOTATION` for unsupported configs. |
| T-04-01-03 | Information Disclosure | `PayloadBuilder.js` | mitigate | Build allowlisted mapped payloads or keys plus metadata only; do not include full entity rows by default. |
| T-04-01-SC | Tampering | npm/pip/cargo installs | mitigate | No package-manager install task exists in this plan; if an executor adds one, stop and run Package Legitimacy Gate before installing. |
</threat_model>
