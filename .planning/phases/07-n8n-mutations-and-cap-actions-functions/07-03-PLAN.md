<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CAP metadata to operation dropdown | Remote metadata controls available Action/Function descriptors. |
| n8n parameters to business-operation requests | Operation name/kind, key values, and Parameters JSON become CAP action/function URLs and request payloads. |
| CAP action/function output to n8n items | CAP operation responses become node output or node-visible errors. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03-01 | Information Disclosure | Action/Function errors and tests | mitigate | Reuse sanitized error helpers and assert credentials, auth headers, Parameters JSON, response bodies, and stack traces do not serialize. |
| T-07-03-02 | Tampering | Action/Function URL construction | mitigate | Normalize service path, operation names, entity sets, manual predicates, and metadata key parts; encode function query parameters instead of string-concatenating raw values. |
| T-07-03-03 | Information Disclosure | Parameters JSON validation | mitigate | Parse parameters locally and return allowlisted validation messages without raw parameter object content. |
| T-07-03-04 | Tampering | bound destructive or mutating actions | mitigate | Require explicit key input through the same hybrid key path as Update/Delete before invoking bound operations. |
| T-07-03-05 | Repudiation | Action/Function mode semantics | mitigate | Tests capture method, path, body/query, and operation kind so actions cannot silently execute as functions or functions as actions. |
| T-07-03-SC | Tampering | npm installs | mitigate | No package installs are planned; package changes require package legitimacy review first. |
</threat_model>
