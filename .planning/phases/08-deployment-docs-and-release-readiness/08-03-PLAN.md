<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CAP/plugin runner to local n8n webhook | The script starts a real local n8n workflow and receives an execution ID. |
| CAP/plugin cancellation to n8n stop API | The script calls plugin cancellation, which calls n8n `POST /api/v1/executions/{id}/stop`. |
| n8n workflow export to repository | The committed fixture can carry instance metadata or credentials if not scrubbed. |
| browser evidence to release status | Human-observed n8n execution state becomes manual evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-03-S | Spoofing | docs/manual-visual-showcase.md | mitigate | Require browser-visible waiting/running execution before cancellation, an explicit running webhook response contract in the fixture, and browser-visible stopped/cancelled state after CAP/plugin stop. |
| T-08-03-T | Tampering | test-workflows/cancellation-workflows.json | mitigate | Integration gate asserts workflow name, webhook path, executionId response, explicit running marker, Wait node, and forbidden field absence. |
| T-08-03-R | Repudiation | scripts/cancellation-showcase.js | mitigate | Print sanitized execution ID, n8n execution ID, cancellation result, and cleanup instructions without printing API keys. |
| T-08-03-I | Information Disclosure | fixture, script, docs | mitigate | Use placeholders only; gate against API keys, bearer tokens, Basic Auth headers, private keys, owner/project/shared metadata, personal emails, request bodies, response bodies, and stack traces. |
| T-08-03-D | Denial of Service | stoppable workflow | mitigate | Wait duration is bounded and cleanup/deactivation steps are documented; fixture is isolated from the happy-path workflow fixture. |
| T-08-03-E | Elevation of Privilege | n8n stop API key | mitigate | Docs require local review API key only, name minimum execution stop/list scope where n8n supports scopes, and do not commit key values. |
| T-08-03-SC | Tampering | npm installs | mitigate | No package installs are planned; use existing CAP, n8n, Docker Compose, and Vitest tooling. |
</threat_model>
