<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| docs to developer setup | README, focused docs, and `.env.example` guide local and cloud configuration. |
| docs to platform guidance | BTP advisory content may be mistaken for validated deployment instructions. |
| evidence matrix to GitHub status | Release-readiness evidence informs issue/project movement. |
| examples and fixtures to repository | Placeholder config and workflow fixtures can accidentally leak secrets or personal metadata. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-04-S | Spoofing | docs/release-readiness.md | mitigate | Use exact evidence states and require browser/manual evidence before claiming real n8n or cancellation verification. |
| T-08-04-T | Tampering | .env.example and README commands | mitigate | Smoke tests assert expected env groups, README links, and `npm run review:local`; no hidden command substitution or `.env` ingestion. |
| T-08-04-R | Repudiation | GitHub story evidence mapping | mitigate | Map requirement IDs, success criteria, and GitHub issues #16-#18, #19-#27, #29, and #30 to files, commands, fixtures, and evidence state. |
| T-08-04-I | Information Disclosure | .env.example, docs, scripts, fixtures | mitigate | Use empty or angle-bracket placeholders only; gate for API keys, bearer tokens, Basic Auth headers, private keys, OAuth secrets, personal emails, owner/project/shared metadata, and production URLs. |
| T-08-04-D | Denial of Service | BTP guidance and review command | mitigate | Keep BTP as advisory; do not require CF/Kyma tooling or live n8n browser state for automated readiness. |
| T-08-04-E | Elevation of Privilege | BTP and n8n credential guidance | mitigate | Direct readers to service bindings, secret stores, destinations/connectivity, and least-scope n8n API keys; do not document reusable credentials. |
| T-08-04-SC | Tampering | npm installs | mitigate | No package installs are planned; final checks use existing workspace dependencies. |
</threat_model>
