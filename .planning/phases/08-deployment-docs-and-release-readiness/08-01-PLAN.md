<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer shell to review command | Local command execution aggregates build, smoke, integration, compile, and validation evidence. |
| command output to release evidence | Warnings and failures become evidence labels that reviewers may rely on. |
| repository examples to user environment | Script sources can accidentally include real env names, secret values, or credential-loading behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01-S | Spoofing | scripts/review-local.js | mitigate | Print exact command labels and child-process exit codes so a passing review command cannot hide which checks ran. |
| T-08-01-T | Tampering | package.json review:local script | mitigate | Smoke test asserts `review:local` points to `node scripts/review-local.js` and the helper names the deterministic command list. |
| T-08-01-R | Repudiation | warning classification output | mitigate | Emit exact labels `fix before release`, `accepted tooling warning`, and `manual/UAT evidence required`; fail on unclassified warning-like output per D-24. |
| T-08-01-I | Information Disclosure | scripts/review-local.js and command output | mitigate | Do not read `.env`, do not accept API-key flags, do not print env values, and source-gate for tokens, private keys, bearer strings, copied Basic Auth headers, and literal `N8N_API_KEY=` values. |
| T-08-01-D | Denial of Service | review:local command | mitigate | Keep checks deterministic and local; exclude Docker daemon, browser login, screenshots, real n8n runtime, and cloud/BTP tooling per D-21 and D-22. |
| T-08-01-E | Elevation of Privilege | child process runner | mitigate | Run fixed command arrays without shell interpolation for npm, CAP compile, and validator commands. |
| T-08-01-SC | Tampering | npm installs | mitigate | No package installs are planned; use existing npm, Vitest, CAP, and workspace tooling. |
</threat_model>
