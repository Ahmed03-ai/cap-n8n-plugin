<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local package build to n8n container | Built community-node files are staged for n8n to load as custom extensions. |
| browser operator to local n8n profile | Reviewer enters transient owner/login and CAP credential values in n8n UI. |
| n8n container to host CAP app | n8n calls CAP OData through `http://host.docker.internal:3000`. |
| manual evidence to release status | Browser checklist results become VERIFY-07 release-readiness evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-02-S | Spoofing | docs/local-n8n-custom-node-e2e.md | mitigate | Require visible `SAP CAP` node, credential Test Connection, metadata dropdown, and operation results before evidence can move beyond `manual UAT required`. |
| T-08-02-T | Tampering | scripts/prepare-n8n-custom-node.js | mitigate | Install only the locally packed workspace tarball into `.n8n-review-data/custom/node_modules/n8n-nodes-sap-cap` and fail if manifest paths `dist/nodes/SapCap/SapCap.node.js` or `dist/credentials/SapCapApi.credentials.js` are missing. |
| T-08-02-R | Repudiation | manual E2E checklist | mitigate | Checklist captures URL, visible n8n node/editor state, credential test result, each operation result, and cleanup confirmation. |
| T-08-02-I | Information Disclosure | docs, compose file, helper script | mitigate | Use isolated local profile, placeholders only, no `.env` reads, no credential exports, no real n8n login values, no Basic Auth header literals, and no API keys in committed files. |
| T-08-02-D | Denial of Service | local n8n review profile | mitigate | Keep profile opt-in through `docker-compose.n8n-node.yml`; default local n8n remains unchanged, and cleanup command is documented. |
| T-08-02-E | Elevation of Privilege | n8n custom extensions | mitigate | Load only the local package under `.n8n-review-data/custom/n8n-nodes-sap-cap`; do not enable registry-managed community package reconciliation. |
| T-08-02-SC | Tampering | npm installs | mitigate | Use only a local `npm pack` tarball installed inside the mounted custom directory; do not install the community node from npm registry or read secrets during install. |
</threat_model>
