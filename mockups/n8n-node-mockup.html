Query mode — "I need a list"

Use this when you don't know which records you want yet. You can filter, sort and paginate. Returns an array — each record becomes a separate item in n8n for the next node to process.

Use this when a previous step already gave you an ID. No filtering or sorting — just provide the key and get that exact record back. Returns a single object, not a list.
